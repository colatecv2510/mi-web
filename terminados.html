Terminado

Portfolio CI/CD en Cloudflare Pages

Arquitectura final

Sitio estático sin framework. Cada push a la rama principal valida el HTML y se publica en Cloudflare Pages, que lo sirve desde su red global con TLS automático.

Decisiones técnicas

  • Sitio estático. HTML, CSS y JavaScript propios, sin framework ni dependencias JS de terceros.
  • Despliegue continuo. Cada git push valida el HTML y publica sin pasos manuales.
  • Cabeceras estrictas. Content-Security-Policy, X-Frame-Options: DENY y nosniff.
  • CV imprimible. Reglas @media print que exportan la portada a una página A4.

Resultados

  • Publicación automática en cada cambio, con certificado TLS y caché global.
  • Cero dependencias JS de terceros en el navegador del visitante.
  • Portada exportable a PDF con Ctrl + P.
